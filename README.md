# SYNCFIT

창의역량1 9조 철모팀의 손목·발목 웨어러블 기획 **SYNCFIT**의 프로토타입입니다.

- **카메라 프로토타입:** https://02setoff.github.io/syncfit/
  밴드 4개 대신 휴대폰 카메라(MediaPipe Pose)가 손목·발목을 읽어 가상 밴드로 자세 신호를 줍니다. 영상은 기기 안에서만 분석합니다.
  덤벨 컬·제자리 걷기·스텝 터치마다 3D 예시 영상이 있어, 운동을 고르고 ‘3D 예시 영상으로 체험’을 누르면 카메라 없이 볼 수 있습니다.
- **3D 사용 장면 영상 (61초):** https://02setoff.github.io/syncfit/video.html

영상 속 기기·앱 화면은 콘셉트이며 실제 제품이 아닙니다.
